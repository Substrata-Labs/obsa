# OBSA: Obligation-Based Systems Assurance

An ontology for compositional quality assurance in complex systems.

OBSA formalizes the *obligation* as an independent computational artifact occupying the layer between stakeholder requirements and engineering designs. The obligation is both design-independent (it does not prescribe implementation) and directly testable (it can be verified without knowing which design satisfies it).
